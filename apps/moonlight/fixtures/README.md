# Moonlight test data

This is what the Moonlight app's tests use (`contract.json`).

There's nothing recorded here. Moonlight is a normal program: the box starts it from the `exec` line in its manifest. It's already on every box, so adding the app just puts it on home. The app has no page and doesn't talk to a server.

So the tests check that the app follows OrigaiTV's rules for an official app, that opening it doesn't do or ask for anything, and that it can't be asked to do anything else.

Pairing with your PC is Moonlight's own, on the TV, and so is picking a game to stream.

The rest needs Moonlight on an installed box and a PC to stream from: that it opens, pairs and streams, and that holding the guide button gets you home. I'll check that on my NUC with a controller.
